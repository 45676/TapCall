# 贴卡拨号（TapCall）

> 许可证：**GPL-3.0**（见 [LICENSE](LICENSE)）　｜　纯离线 · 无广告 · 无统计 · 无第三方 SDK

给家里老人用的极小工具：**手机贴一下 NFC 卡片，直接拨打设定好的号码。**

- 写入端：任何带 NFC 的安卓机（本项目在红米 Turbo 5 Max 上验证通过）
- 使用端：装了本 App 的安卓手机（老人机、家人机）
- 不做免提、不联网、不收集任何数据，全部功能在本地

## 一、安装

1. 把 `TapCall.apk` 传到手机（微信/QQ/USB 均可）；
2. 点开安装，系统提示"未知来源"时选择允许；
3. 打开 App「贴卡拨号」。

## 二、首次设置（只做一次，很重要）

### 1. 授权拨号权限
打开 App 会弹出"允许拨打电话？"，选 **允许**。
若之前拒绝过：点 App 里的「授权拨号权限」按钮，或到 设置 → 应用 → 贴卡拨号 → 权限 → 电话 → 允许。

> 没授权也能用，但贴卡后只会打开拨号盘（还要按一下拨号键），不会直接拨出。

### 2. 打开后台运行权限（小米/红米 HyperOS 必做）
设置 → 应用设置 → 应用管理 → 贴卡拨号：
- **后台弹出界面：允许**（默认是拒绝的，不开这项贴卡不会自动拨号）
- **自启动：允许**
- **省电策略：无限制**

华为/荣耀：手机管家 → 应用启动管理 → 贴卡拨号 → 手动管理（三项全开）
OPPO/一加/vivo：设置 → 电池 → 应用耗电管理 → 允许后台运行 / 允许自启动

### 3. 确认 NFC 已开启
App 主界面会显示「NFC：已开启 ✓」。未开启时点「打开 NFC 设置」。

## 三、日常使用

在**红米**（写入端）上：
1. 输入号码（如 `13800138000`），点「保存号码」；
2. 点「① 写入卡片（家里人手机：贴卡直接拨出）」；
3. 把卡片贴到手机背面 NFC 天线位置（一般是摄像头附近），看到「写入成功」即可。

在**老人机**（使用端）上：
4. 贴一下卡片 → 手机自动拨出号码。

## 四、两种写卡模式的区别

| 模式 | 卡片内容 | 效果 |
| --- | --- | --- |
| ① 家里人手机（推荐） | `tapcall:号码` + `tel:号码` 两条记录 | 装了本 App 的手机：**贴卡直接拨出**；没装的手机：多数无反应 |
| ② 通用 | 只写 `tel:号码` | 任何安卓手机贴卡都会弹出**已填好号码的拨号盘**，需按一下拨号键 |

> v1.0.1 起模式① 也把 `tel:号码` 放在**第一条**（自定义记录放第二条）：这样没装 App 的手机至少能弹拨号盘，装了 App 的手机则由 App 直接拨出。**旧版写的卡请重新写一次。**

给家里人用就选 ①，两张卡模式可以混用。

## 五、第一次测试（3 分钟，务必走一遍）

1. 先在**写入端**（红米）装好 App，输入号码 → 保存 → 「① 写入卡片」→ 贴卡 → 看到"写入成功"；
2. **把卡片从写入手机上拿开**（重要：写完后 20 秒内本机不会拨号，但也别一直贴着）；
3. 拿**老人机**（已装 App、已授权、已开后台弹出界面）贴卡 → 应立即出现拨号界面并拨出；
4. 若没反应：先看老人机贴卡时有没有"震动/提示音"——
   - 完全没反应 → 手机 NFC 没开，或卡片没贴准（对准摄像头附近，贴稳 1 秒）；
   - 有震动但不拨号 → 多半是"后台弹出界面"没开，或拨号权限没给；
   - 弹出拨号盘但要按一下 → 拨号权限没授权（点 App 里的「授权拨号权限」）。

## 六、常见问题

**❗ 手机弹出「发现NFC卡片 / 检测到多次读取NFC卡片后均未处理」**
这是手机系统在说：**卡片被读到了，但没有任何 App 处理它**。三种原因，按顺序排查：
1. **测试的手机没装「贴卡拨号」**——模式①的卡必须在装了 App 的手机上才会自动拨号；
2. **「后台弹出界面」没允许**——App 被系统拦住，贴卡等于没反应；
3. **卡是用旧版写的**——旧版把自定义记录放在第一条，没装 App 的手机识别不了、也不会自动看第二条。**用新版（v1.0.1 起）重新写一次卡即可**：现在 tel: 记录放在第一条，任何手机都能识别。

> 顺便提醒：这条系统通知里的「去设置」**不要点**——那个选项会把 NFC 限制成"仅系统可识别卡片"，会让第三方 App 更收不到卡。忽略这条通知即可。

**❗ 贴卡后弹出「是否拨打电话 xxx」确认框（小米/HyperOS）**
链路已经通了（App 收到了卡片、也发出了拨号请求），卡在手机自己的二次确认上。按顺序处理：
1. **双卡设置**：设置 → 双卡与移动网络 → 拨号 / 默认拨号卡 → **指定"卡1"或"卡2"，不要选"每次询问"**。v1.0.2 起 App 也会主动指定第一张卡。
2. **换拨号方式**：主界面点「切换拨号方式」，依次试：
   - **只用 Telecom 直拨**（走电信服务，最可能绕开 ROM 对 ACTION_CALL 的拦截）；
   - **只用 ACTION_CALL**（标准做法）；
   - **只用系统拨号盘**（保底，会停在拨号盘，按一下拨出）。
3. 如果三种方式都弹确认框：说明这个 ROM 对第三方应用直接拨号做了强拦截，唯一彻底解法是把「贴卡拨号」设为**默认电话应用**（需要额外实现来电界面，代价较大；需要时再单独做）。

**贴卡后没反应，怎么知道卡里到底写了什么？**
主界面点「**检查卡片内容（不拨号）**」，贴一下卡，屏幕会显示 UID、技术支持、每条记录的内容和解析出的号码，并直接告诉你问题出在哪。


**贴卡没反应？**
- 该手机没装 App，或装的是模式②的卡（模式①需要装 App）；
- 「后台弹出界面」没打开（小米默认拒绝，最常见原因）；
- 手机 NFC 没开；或卡片贴的位置不对（对准摄像头附近，贴稳 1 秒）。

**贴卡后只弹出拨号盘，没有直接拨出？**
- 拨号权限没授权 → 点 App 里的「授权拨号权限」。

**提示"这张卡不支持 NDEF 写入"？**
- 卡片是门禁卡/MIFARE Classic，或已经被设成只读；换 NTAG213/215/216 白卡即可。

**提示"卡片容量不够"？**
- 卡容量太小（比如 MIFARE Ultralight 只有 48 字节），换 NTAG213 及以上。

**熄屏贴卡没反应？**
- 部分机型熄屏时不分发 NFC，需要先按一下电源键亮屏；建议实测几次确认。

**想改号码？**
- 在 App 里改好号码，重新写一次卡即可（同一张卡可反复写，除非被设为只读）。

## 七、待机模式（小米/红米上必须用它）★ 已实测可用

**为什么必须用它**：小米系统会拦截"**后台应用发起的拨号**"，贴卡后必弹「是否拨打电话」确认框 —— 换哪种拨号方式都一样。
**待机模式**让 App 一直待在前台，由它自己读卡、自己拨号，不再是"后台应用发起的"，因此**不会被拦**（已在小米/红米机型上验证）。

**两张卡的用法（推荐）**
- **唤醒卡**：卡里不存号码，贴一下只负责"打开 App 并进入待机页"。用主界面的「**★ 写入唤醒卡**」写一张，贴在手机附近或桌面上；
  - 写入的是 **AAR（Android 应用记录，类型 android.com:pkg → 包名 com.family.tapcall）**：这是系统级"打开这个包"的记录，**锁屏、App 被清理、刚重启都能拉起来**（自定义 URI 在这类 ROM 上会被拦，所以改用 AAR）；
  - 卡里同时带一条 tapcall:standby 标记，App 在待机页读到它时只会提示"已经是待机模式"，**不会误拨**；
- **拨号卡**：存号码，贴一下直接拨出（App 已在前台，不会被系统拦）。用「① 写入卡片」写，**一张号码一张卡**，可以写多张（儿子/女儿/社区医生）。

日常流程：**先贴唤醒卡 → 手机出现"请把卡片贴到手机背面" → 再贴要打的那张拨号卡 → 直接拨出。**
好处：手机锁屏、重启、App 被清理掉之后，贴一下唤醒卡就恢复到待机状态；拨号卡可以做好几张，共用同一张唤醒卡。

**用法（老人机）**
1. 点桌面上的「贴卡拨号」图标 —— 打开后**会自动进入待机页**（默认开启）；
2. 把这一页一直开着，手机放桌上；
3. 贴卡 → 直接拨出，页面显示"已拨号：xxx"；
4. 通话结束后回到这一页，可以继续贴卡。

**待机页的按钮布局**

```text
        请把卡片贴到手机背面
   流程：先贴唤醒卡 → 再贴要拨的那张卡
              已拨号：138xxxx
        通道：ACTION_CALL（22:34:06）

  ┌───────────────────────────────┐
  │      长按这里退出待机          │   ← 大按钮（主操作，长按 1 秒以上）
  └───────────────────────────────┘
   返回键与左右滑返回手势已屏蔽，只能长按上面的大按钮退出

           （ 🔒 固定屏幕 ）              ← 小号红色按钮
   解除固定屏幕的方式：
   1) 按住返回键（全面屏：上滑并按住）→ 出现提示后解锁屏幕；
   2) 或到 设置 → 安全（更多设置）→ 屏幕固定 里关闭。
   开启前需先在系统里打开「屏幕固定」开关。
```

- **退出**：长按大按钮（单击只提示，不退出）；返回键与左右滑返回手势均已屏蔽；
- **固定屏幕**（可选）：先到 设置 → 安全（或"更多设置"）→ 屏幕固定 打开开关，再点小红按钮；固定后 Home 手势和最近任务也用不了，手机锁死在本页；
- 不想锁就跳过固定屏幕，屏蔽返回已经够日常使用。
**误退了怎么办**：再点一次桌面图标就回到待机页。

> 建议：老人机固定放家里时接上充电器（待机页屏幕常亮，比较耗电）。
> 想关掉"打开即待机"：主界面点「开关：打开 App 自动进待机」。

## 八、隐私与权限

**完全离线**：AndroidManifest 中未申请 `INTERNET` 权限 —— 不联网、无广告、无统计、无第三方 SDK。号码等设置只保存在本机应用私有目录（卸载即删除），卡里的号码保存在卡片本身，不经过任何服务器。

| 权限 | 用途 |
| --- | --- |
| `android.permission.NFC` | 读取卡片内容；被唤醒卡拉起进入待机页 |
| `android.permission.CALL_PHONE` | 贴卡后直接拨出设定号码（未授权时退化为打开拨号盘，需按一下） |

**首次启动会先展示《隐私政策》**，点「同意并继续」之后才会申请拨号权限；未同意时贴卡与待机模式都不会工作。隐私政策可在「关于 / 隐私政策」中随时查看。

**应用备案号**：本应用未在国内应用商店上架，因此无需 App 备案；「关于」页已保留备案号展示位置，将来如上架会在此处展示。

## 九、自己重新编译

源码就是本目录，编译不需要 Gradle 或 Android Studio，只用 Android SDK 自带的命令行工具：

**前置**：JDK 17、Android SDK（`platforms;android-34`、`build-tools;34.0.0`）、Python 3（仅用于把 dex 打进 APK）。

```powershell
# 基本用法（SDK/JDK 装在别处时用参数指定）
powershell -ExecutionPolicy Bypass -File .\build.ps1 -Sdk <SDK路径> -Jdk <JDK路径> -Python python

# 签名库口令的三种提供方式（任选其一）
#   1) -StorePass "口令"
#   2) 设置环境变量 TAPCALL_KS_PASS
#   3) 在项目上一级目录放一个 tapcall_keystore.pass 文件，内容为口令
```

编译脚本会先把源码复制到一个纯 ASCII 的临时目录（`aapt2`/`d8` 等原生工具无法处理中文路径），再把生成的 `TapCall.apk` 拷回本目录。

也可以把 `src/`、`res/`、`AndroidManifest.xml` 直接拷进 Android Studio 新建的空项目里编译。

## 十一、代码结构

| 文件 | 作用 |
| --- | --- |
| `MainActivity.java` | 主界面：设置号码、写卡入口、测试拨号、权限与 NFC 状态 |
| `WriteTagActivity.java` | 写卡：等待贴卡 → 写 NDEF（必要时先格式化） |
| `CallTagActivity.java` | 贴卡后被系统拉起：解析号码 → `ACTION_CALL` 直接拨出 |
| `TapCall.java` | 号码清洗 + NDEF 记录构造/解析 |
| `Prefs.java` | 保存号码与模式 |
| `CardCheckActivity.java` | 自检：贴卡显示 UID / 技术支持 / 每条 NDEF 记录与解析结果 |
| `StandbyActivity.java` | 待机模式：前台常开页面，自己读卡并拨号 |
| `PrivacyActivity.java` | 隐私政策（首次启动必须先同意，之后才申请权限） |
| `AboutActivity.java` | 关于：版本、备案号位置、开源地址、隐私政策入口 |
| `Dialer.java` | 拨号策略：Telecom 直拨 / ACTION_CALL / 系统拨号盘 |

签名库 `tapcall.jks` **只保存在本地，不进入本仓库**（`.gitignore` 已排除）。编译时口令按此顺序查找：`-StorePass` 参数 → 环境变量 `TAPCALL_KS_PASS` → 项目上一级目录的 `tapcall_keystore.pass` 文件。请自行备份签名库，**丢失后无法覆盖安装升级**。
